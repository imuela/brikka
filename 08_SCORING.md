# BRIKA — SCORING V1

## Objetivo

Proporcionar una herramienta explicable de apoyo al análisis hipotecario.

## Componentes

- Client Score
- Property Score
- Operation Score

## Reglas

Las reglas serán configurables por rule set y versión.

## Resultado

El resultado incluirá:
- score;
- rating;
- fecha;
- versión de reglas;
- desglose.

## Principio

El scoring no representa aprobación bancaria ni sustituye al broker.

## Histórico

Los resultados relevantes se conservarán para poder explicar decisiones anteriores.
