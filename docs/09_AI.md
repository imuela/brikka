# BRIKA — AI SPECIFICATION V1

## Arquitectura

Domain/Application → AI Gateway → Provider.

## Objetivos

Desacoplar el dominio de proveedores de IA y controlar seguridad y costes.

## Casos de uso

Posibles funciones V1:
- extracción de datos documentales;
- resumen;
- asistencia al broker;
- detección de documentación;
- generación asistida de comunicaciones.

Cada caso de uso deberá aprobarse funcionalmente antes de implementarse.

## Seguridad

La IA sólo recibirá datos autorizados.

No se enviará información de un tenant a otro.

## Trazabilidad

Registrar:
- empresa;
- usuario;
- operación;
- proveedor;
- modelo;
- operación IA;
- tokens;
- coste estimado;
- timestamp.

## Principios

IA como asistencia, no como autoridad final en decisiones hipotecarias.
